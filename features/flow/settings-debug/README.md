# @features/flow-settings-debug

> [!CAUTION]
> **Status: UNSTABLE**. New package, in active development.

The Debug section of the new Settings of Ledger Wallet mobile and desktop (Settings 4.0), shown
behind the `newSettings` feature flag. The legacy Settings stay in the apps, untouched, until the
flag reaches 100%.

Built on the shell package `@features/flow-settings`, part of the
[Settings 4.0 epic](https://ledgerhq.atlassian.net/browse/LIVE-41813).

## Consumers

Ledger Wallet Desktop and Ledger Wallet Mobile.
