# @features/flow-settings-asset-management

> [!CAUTION]
> **Status: UNSTABLE**. New package, in active development.

The Asset management section of the new Settings of Ledger Wallet mobile and desktop (Settings 4.0),
shown behind the `newSettings` feature flag: hide empty token accounts, hide token transactions
worth 0, hidden tokens and crypto assets settings. The legacy Settings stay in the apps, untouched,
until the flag reaches 100%.

Part of the [Settings 4.0 epic](https://ledgerhq.atlassian.net/browse/LIVE-41813), built on the
shell package `@features/flow-settings`. The section itself comes with
[LIVE-41836](https://ledgerhq.atlassian.net/browse/LIVE-41836).

## Consumers

Ledger Wallet Desktop and Ledger Wallet Mobile.
