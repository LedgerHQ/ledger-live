# @features/flow-pay-card-widget

> [!CAUTION]
> **Status: UNSTABLE** — In active development; API may change.

Card widget flow for the Pay tab in Ledger Wallet.

This package is currently a skeleton: it exposes a dual-platform public API (web via
[`src/index.ts`](src/index.ts), native via [`src/index.native.ts`](src/index.native.ts)) with no
components yet. Add flow UI, view models and state under `src/` as the widget is built out, and
export them through [`src/exports.ts`](src/exports.ts).
