# @features/flow-settings-privacy

> [!CAUTION]
> **Status: UNSTABLE**. New package, in active development.

The Privacy section of the new Settings of Ledger Wallet mobile and desktop (Settings 4.0), shown
behind the `newSettings` feature flag: bug reports, app performance, personalized experience and
the privacy policy. The legacy Settings stay in the apps, untouched, until the flag reaches 100%.

Part of the [Settings 4.0 epic](https://ledgerhq.atlassian.net/browse/LIVE-41813), built on the
shell package `@features/flow-settings`. The section itself comes with
[LIVE-41833](https://ledgerhq.atlassian.net/browse/LIVE-41833).

## Consumers

Ledger Wallet Desktop and Ledger Wallet Mobile.
