Split the monolithic `ledger-wallet-cli` agent skill into a thin umbrella/router skill plus five task-scoped skills (`ledger-wallet-cli-account-discover`, `-receive`, `-send`, `-swap`, `-genuine-check`). The umbrella keeps the intent map and the supporting commands (`session`, `balances`, `operations`, `assets`) and points to the task skills; each task skill is self-contained (informal-request mapping, flags, task errors). Cross-cutting hardware-wallet safety rails now live in one canonical `references/safety.md` that each task skill symlinks (relative), so there is a single edit point and zero drift — the embed codegen resolves the symlink so every skill ships an identical copy. `skill retrieve` and `skill install` now require an explicit skill name (they list the available skills when omitted; `install` also suggests `--all`), the sole-skill defaulting is gone, and the first-run nudge now points at `wallet-cli skill install --all` (still per-agent tailored). The developer-portal skill-sync GitHub workflow now auto-discovers and syncs every shipped wallet-cli skill and dereferences the shared `safety.md` symlink so the real content is uploaded.
