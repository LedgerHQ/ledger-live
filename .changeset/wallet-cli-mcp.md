Add a `wallet-cli mcp` stdio Model Context Protocol server that exposes every wallet-cli operation as a typed MCP tool (`account_discover`, `session_view`, `session_reset`, `balances`, `operations`, `receive`, `send`, `swap_quote`, `swap_execute`, `swap_status`, `genuine_check`, `assets_token`, `assets_token_by_id`). Both the CLI handlers and MCP tools call the same command core, so tools return byte-for-byte the same envelopes as `--output json`, and device-touching tools emit MCP progress notifications and surface the same `code`/`exitCode` error taxonomy. Device access is serialized behind a single lock (the USB HID channel does not multiplex). Ships a new `ledger-wallet-cli-mcp` agent skill (setup snippets for Claude Code, Claude Desktop/Cursor, and Codex plus the tool list, with the shared hardware-wallet `references/safety.md` symlinked like the other task skills), and documents the MCP server (start command, per-agent config, tool table, safety notes) in the README and umbrella skill. The skill embeds into the binary via `skill list`/`retrieve`/`install` and is auto-synced to the developer portal alongside the other wallet-cli skills.
