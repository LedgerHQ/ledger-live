# LIVE-36152 — [HEDERA] Migrate mobile staking UI to the generic transaction shape

- Epic: LIVE-29812 · Status: TO DO · Estimate proposed: 3 SP
- https://ledgerhq.atlassian.net/browse/LIVE-36152

## Description

The same change as on desktop, for Ledger Live Mobile: move the Hedera staking flows off
`transaction.properties.stakingNodeId` and onto the generic transaction's `valId`.

Eight files across the same four staking flows — delegation, redelegation, undelegation and claim
rewards. Reads and writes are entangled in the same components, so they move together.

Two extras on mobile:

- Two integration fixture sets assert the old shape and must move with the code.
- One fixture outside the Hedera family, in the notifications-prompt feature, also builds a Hedera
  transaction with the old field. That one is **test-only** — the feature has no product code reading
  the field — so it is a fixture to update, not a hidden consumer.

## Acceptance criteria

- [ ] All four staking flows complete on mobile against the generic bridge
- [ ] The selected node id is carried correctly from selection through to the signed transaction
- [ ] No mobile component reads `transaction.properties` for Hedera
- [ ] Both Hedera flow fixture sets and the notifications-prompt fixture are updated
- [ ] Existing mobile tests updated
