# Validation Before Finishing

Before finishing any agentic code change, run the [validate-changes](../.agents/skills/validate-changes/SKILL.md) skill and add its steps to your todo list. When there are relevant dev or build tasks, run them too to detect any issues.

Local README.md files and package.json scripts take priority for package-specific commands. Fall back to [repo-commands](./repo-commands.md) for general guidance and gotchas.
