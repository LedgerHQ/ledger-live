# @devtools/account-receive

The receive kind of each account (`@domain/entity-account-receive`): its address, how the device confirms it, its shielded address if any, the source that answered, the last error, and a button to read it again.

Imports no `@devtools/*` package, as any tool ([import boundaries](../../.claude/skills/devtools-import-boundary/SKILL.md)). Its props come from `useAccountReceiveToolProps` in `@devtools/bindings`.
