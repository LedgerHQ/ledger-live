# @devtools/account-analytics-introduction

Shows whether the Account Detail card that redirects to Analytics (`@features/flow-account-detail-analytics-notice`) was dismissed, and resets it so it shows again.

Imports no `@devtools/*` package, as any tool ([import boundaries](../../.claude/skills/devtools-import-boundary/SKILL.md)). Its props come from `useAccountAnalyticsIntroductionToolProps` in `@devtools/bindings`.
