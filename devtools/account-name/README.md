# @devtools/account-name

The account names slice (`@domain/entity-account-name`): each name with its legacy id and the `AccountUUID` behind it, and a lookup of a name by `AccountUUID`.

Imports no `@devtools/*` package, as any tool ([import boundaries](../../.claude/skills/devtools-import-boundary/SKILL.md)). Its props come from `useAccountNameToolProps` in `@devtools/bindings`.
