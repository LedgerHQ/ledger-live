# @devtools/account-operation

The operations kind of each account (`@domain/entity-account-operation`): its loaded rows, the source that answered, the last error, and buttons to read its head again or its next page.

Imports no `@devtools/*` package, as any tool ([import boundaries](../../.claude/skills/devtools-import-boundary/SKILL.md)). Its props come from `useAccountOperationToolProps` in `@devtools/bindings`.
