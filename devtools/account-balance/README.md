# @devtools/account-balance

The balance kind of each account (`@domain/entity-account-balance`): its rows, the source that answered, the last error, and a button to read it again.

Imports no `@devtools/*` package, as any tool ([import boundaries](../../.claude/skills/devtools-import-boundary/SKILL.md)). Its props come from `useAccountBalanceToolProps` in `@devtools/bindings`.
