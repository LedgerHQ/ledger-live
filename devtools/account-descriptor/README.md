# @devtools/account-descriptor

The accounts slice (`@domain/entity-account`): each account's `AccountUUID`, descriptor and legacy id, as a table.

Imports no `@devtools/*` package, as any tool ([import boundaries](../../.claude/skills/devtools-import-boundary/SKILL.md)). Its props come from `useAccountDescriptorToolProps` in `@devtools/bindings`.
