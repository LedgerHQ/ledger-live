# Tools

Use this directory as a home for developer experience tooling that doesn't belong to a specific app or library.

## What it contains

- CI actions
- GitHub bots
- Nx plugins
- Build utilities
- pnpm hook helpers

## What it does not contain

- Business logic
- Code specific to a particular app or library

## Related

`scripts` is a duplicate of this directory. Contents should be migrated to here in good time.

`devtools` is a stand-alone debugging component and belongs in its own directory.
